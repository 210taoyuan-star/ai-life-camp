手機拍照上傳的「三不原則」（牢記保平安）

  • 不拍正臉與證件：身分證、駕照、護照、全家福正臉，沒事千萬不要丟。
  • 不拍密碼與金融：存摺帳號、提款卡背面三碼、家裡 Wi-Fi 密碼貼紙。
  • 不直接照單全收：法律合約、健康用藥劑量、大筆金錢決策，AI 負責幫你「看懂與整理問題」，最後決定永遠找真人專家確認。

LINE 天天用得上的 7 個實戰技巧

1. 照片 [A] 轉文字：點開照片按右上角 [A]，直接框選文字複製，不用手打。
2. 無聲訊息：設定 ➔ LINE Labs 開啟。長按送出鍵選「無聲訊息」，半夜清晨傳訊不擾人。
3. 匿名截圖：長按訊息選截圖 ➔ 左下角「匿名處理」，人名頭貼秒變可愛小動物。
4. 設為公告釘選：聚會時間、匯款帳號長按設為公告，置頂免翻找。
5. 官方查證機器人：加「LINE訊息查證」或「MyGoPen」，長輩可疑連結一鍵辨真偽。
6. 刪除快取瘦身：設定 ➔ 聊天 ➔ 刪除資料 ➔ 勾選「快取」，瞬間清出好幾 GB。
7. 自己的備忘群組：建一個只有自己的群組，把要記的照片、連結、地址丟進去，再搭配「Keep 筆記」收藏，比翻相簿快多了。
